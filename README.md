## Weather App React Native README.md

### Introduksjon

Weather App React Native er en app som hjelper brukere med å vise være basert på dems enhetsgeolokasjon.

### Hvordan appen fungerer

1. **Bruker Lokasjon:** Brukeren må gi appen tilgang til sin lokasjon sånn at appen vet hvilken data den skal hente.
2. **Dagens:** Appen bruker enhetsgeolokasjon for å vise dagens vær der brukeren befinner seg.
3. **Imorgen:** Appen bruker enhetsgeolokasjon for å vise været for morgendagens 24 timer.
4. **Uken:** Appen bruker enhetsgeolokasjon for å vise været for den neste uken.

### Hvordan få API'en til å fungere

1. Selv om https://api.met.no/ ikke krever en nøkkel så krever det at man oppgir kontakt informasjon i "User-Agent"
2. Opprett en .env fill.
3. lag en variabel kalt CONTACT_INFO og gi den din kontakt informasjon.
